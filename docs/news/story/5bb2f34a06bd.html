YesWiki 4.6.0 before 4.7.0 and 5.0.0-alpha1 before 5.0.0-alpha4 contains an unauthenticated SQL injection…

First reported 22:17 SGT, 25 Oct 2026 · CVE-2026-116207 · CVSS 8.8

CVE-2026-116207 (CVSS 8.8) is an unauthenticated SQL injection in YesWiki's public Bazar search API, in versions 4.6.0 before 4.7.0 and 5.0.0-alpha1 before 5.0.0-alpha4. Attackers could read data such as user password hashes or exhaust database threads.

Why it matters

An unauthenticated SQL injection in a web app that can expose password hashes is a serious cybersecurity risk.
